Original (licensed) fonts for "Dictator in Diapers" / "Dittatore in Culla"
==========================================================================

Put the font files here. The page finds and uses them by itself
(just reload; .woff2, .woff, .otf and .ttf all work).
If a file is missing, the page uses the free Google Fonts stand-in.

Expected file names (extension may vary; spaces, dashes and underscores are ignored):

  Canopee                          -> titles in black boxes, book spines   (VJ-Type)
  EditorialNew-Light               -> body text                             (Pangram Pangram)
  EditorialNew-LightItalic         -> italic body text                      (Pangram Pangram)
  DomaineDisplayCondensed-Medium   -> the "%" sign of the result            (Klim)
  Germgoth                         -> gothic masthead

Stand-ins used when a file is missing:
  Canopee -> Noto Serif Display (narrow) · Editorial New -> Instrument Serif
  Domaine Display -> Playfair Display italic · Germgoth -> UnifrakturMaguntia
